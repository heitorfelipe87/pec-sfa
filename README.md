# PEC-SFA

**Painel Executivo de Contratos das Superintendências Federais de Agricultura**

## Descrição

O PEC-SFA é uma plataforma para gerenciamento do ciclo de vida dos contratos administrativos das Superintendências Federais de Agricultura.

O sistema permitirá o controle da execução contratual, vigências, pagamentos, equipes de fiscalização, documentos, indicadores e alertas gerenciais.

## Tecnologias

- Frontend: React + TypeScript
- Backend: FastAPI (Python)
- Banco de Dados: PostgreSQL
- Docker
- Git/GitHub
